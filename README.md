# Bramble Calculator

Basic, scientific and programmer calculator with unit and currency conversion.

Bramble Calculator is part of [Bramble Office](https://github.com/bramble-apps/bramble-office): its source code, issues and releases live in that repository. This repository is its home on GitHub and the base of its Flathub app id, `io.github.bramble_apps.Calculator`.

- Source code: https://github.com/bramble-apps/bramble-office
